# Hokkaido Trip: 5 Days, 4 Nights

Self-drive itinerary for 4 people, Sat 17 Oct – Wed 21 Oct 2026. Fly in and out of Asahikawa Airport (AKJ), pick up a rental car, and drive around Biei and Furano.

**Live page:** https://johnson-1130.github.io/hokkaido-trip/

## Features

- A one-tap "full-day route" at the top of each day: a single Google Maps link chaining that day's sights
- Google Maps and turn-by-turn navigation links for every stop
- Parking lot map and navigation links for places where parking is hard
- Three restaurant picks for every lunch, dinner and late-night snack, each with a short intro to the staple food and two signature dishes
- Chinese translations next to Japanese shop and dish names
- Route map, shopping map and food map that can be tapped to enlarge

## Updating the page

Regenerate the HTML, rename it to `index.html`, then upload it to this repository (Add file → Upload files) using the same file name. The live page refreshes in about a minute.

## Notes

- The page itself is written in Traditional Chinese.
- Opening hours, closing days and prices come from public web sources (compiled 4 Oct 2026). Check Google Maps or the shop's own notice before you go.
- Chinese shop and dish names are translations or transliterations, not official names. Use the Japanese original when searching or ordering.
